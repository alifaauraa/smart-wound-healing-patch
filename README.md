# Smart Wound Healing Patch

## Deskripsi Proyek

Smart Wound Healing Patch merupakan proyek pengembangan prototipe hidrogel berbasis polivinil alkohol (PVA) dan kitosan dengan penambahan daun kelor (*Moringa oleifera*) sebagai komponen bioaktif dan bunga telang (*Clitoria ternatea*) sebagai indikator perubahan pH. Proyek ini bertujuan mengeksplorasi karakteristik hidrogel dan potensi pengembangan material untuk aplikasi penutup luka.

## Tujuan Proyek

1. Membuat prototipe hidrogel berbasis PVA dan kitosan dengan penambahan bahan alami.
2. Mengevaluasi karakteristik fisik dan permukaan hidrogel.
3. Mengamati potensi respons pH melalui indikator bunga telang.
4. Mengevaluasi karakteristik prototipe melalui pengujian *swelling*, kelembapan, pH permukaan, dan antibakteri.

## Bahan Utama

- Polivinil alkohol (PVA)
- Kitosan
- Daun kelor (*Moringa oleifera*)
- Bunga telang (*Clitoria ternatea*)
- Akuades
- Asam asetat

*Catatan: komposisi dan jumlah setiap bahan mengikuti formulasi yang benar-benar digunakan selama pembuatan prototipe.*

## Metode Pembuatan

Prototipe dibuat menggunakan matriks PVA dan kitosan dengan penambahan bahan berbasis daun kelor dan bunga telang. Pembentukan hidrogel dilakukan melalui metode *freeze–thaw* sebanyak tiga siklus. Kondisi akhir hidrogel kemudian diamati untuk mengevaluasi tekstur dan konsistensinya.

## Pengujian Prototipe

| Pengujian | Tujuan |
|---|---|
| Uji *swelling* | Mengetahui kemampuan hidrogel menyerap cairan. |
| Uji kelembapan | Mengevaluasi karakteristik kelembapan sesuai metode pengujian. |
| Uji pH permukaan | Mengetahui nilai pH permukaan hidrogel. |
| Uji antibakteri | Mengevaluasi aktivitas antibakteri melalui pengujian laboratorium. |

Pengamatan perubahan warna akibat perubahan pH juga dapat dicatat sebagai pengujian tambahan untuk mengevaluasi fungsi indikator bunga telang, apabila pengujian tersebut dilakukan.

## Dokumentasi Proyek

Repositori ini memuat dokumentasi perkembangan proyek, daftar bahan dan alat, prosedur pembuatan, prosedur pengujian, data hasil pengujian, foto prototipe, analisis, referensi, dan laporan akhir.

## Keterbatasan

Prototipe masih dalam tahap pengembangan dan memerlukan evaluasi serta optimasi lebih lanjut. Respons perubahan warna tidak dapat digunakan secara langsung untuk memastikan adanya infeksi. Prototipe ini belum tervalidasi untuk penggunaan langsung pada luka manusia.
