# Smart Wound Healing Patch

## 1. Deskripsi Proyek
Smart Wound Healing Patch merupakan proyek pengembangan prototipe hydrogel berbasis polyvinyl alcohol (PVA) dan kitosan dengan penambahan daun kelor (*Moringa oleifera*) sebagai komponen bioaktif serta bunga telang (*Clitoria ternatea*) sebagai indikator respons pH.

## 2. Tujuan
Mendokumentasikan proses pembuatan prototipe, pengujian awal respons terhadap pH, pengamatan karakteristik fisik, serta evaluasi dan pengembangan produk.

## 3. Proses Pembuatan
Prototipe dibuat menggunakan matriks PVA dan kitosan. Bahan tanaman ditambahkan ke dalam formulasi, kemudian campuran diproses menggunakan metode freeze–thaw sebanyak tiga siklus. Kondisi akhir produk dan proses pengeringan didokumentasikan sebagai bagian dari evaluasi prototipe.

## 4. Pengujian
Pengujian awal mencakup pengamatan perubahan warna pada kondisi pH berbeda. Pengujian lanjutan dapat meliputi respons pH menggunakan larutan buffer dan karakteristik fisik hydrogel, seperti swelling ratio.

## 5. Dokumentasi
Repositori ini menyimpan:

- Referensi ilmiah
- Laporan akhir proyek

## 6. Keterbatasan
Prototipe masih memerlukan optimasi dan pengujian lanjutan. Respons warna terhadap pH tidak dapat digunakan sebagai bukti diagnosis infeksi. Produk belum divalidasi untuk penggunaan langsung pada luka.
